GARASJE 45 – NETTSIDE

FILER
- index.html: Innholdet og strukturen på nettsiden.
- style.css: Farger, skrifttyper, layout og mobiltilpasning.
- script.js: Mobilmeny og demonstrasjon av kontaktskjema.

SLIK ÅPNER DU NETTSIDEN
1. Pakk ut ZIP-filen.
2. Åpne mappen Garasje45_website i Visual Studio Code.
3. Finn index.html.
4. Høyreklikk index.html og velg "Open with Live Server" hvis du har Live Server.
   Hvis ikke kan du dobbeltklikke index.html for å åpne siden i nettleseren.
5. Endre tekst, priser, datoer og bilder etter behov.

VIKTIG
Dette er en startversjon til skoleprosjektet. Garasje 45 er fiktivt.
Adresse, priser, arrangementer og e-post er eksempler. Kontaktskjemaet
er kun en demonstrasjon og sender ikke meldinger. Eksterne Google Fonts
og Unsplash-bildet krever internett.

HUSK TIL PROSJEKTET
Ta skjermbilder underveis, skriv arbeidslogg hver uke, test med 3–5 personer,
og forklar hvilke endringer du gjorde etter tilbakemeldinger.
